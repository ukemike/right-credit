# RightCredit - Frontend

## Applications

- **right-credit** - Loan application
- **under-writing** - Underwriting application

## Development

To run the development server:

```sh
npx nx dev right-credit
```

```sh
npx nx dev under-writing
```

## Build

To create a production bundle:

```sh
npx nx build right-credit
```

```sh
npx nx build under-writing
```
